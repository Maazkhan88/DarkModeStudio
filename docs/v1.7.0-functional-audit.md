## 2. Integration Data Integrity & Cascade Elimination

- **Problem in v1.6.4**: `IntegrationEntity` used `@Insert(onConflict = REPLACE)`. Because `IntegrationMetricEntity` and `IntegrationIncidentEntity` have foreign keys with `onDelete = CASCADE`, any periodic integration update deleted all existing metrics and incidents.
- **Remediation in v1.7.0**:
  - Replaced `@Insert(onConflict = REPLACE)` with `@Insert(onConflict = ABORT)` and `@Update` in `IntegrationDao`.
  - Implemented `upsertIntegrationNonDestructively(database, integration)` across `GitHubSyncer`, `SupabaseSyncer`, and `VercelSyncer`.
- **Verification**: `GitHub304Test.http304_preservesChildMetricsAndIncidentsWithoutCascadeDeletion` asserts that 3 child metrics and 1 incident survive repeated 304 syncs and metadata modifications.

## 3. Truthful Telemetry Reporting

- **Problem in v1.6.4**: `SupabaseConnector` and `VercelConnector` had static hardcoded telemetry fallback metrics (42ms, 88% pool, 18.4GB storage, secondme-web.app, 28ms).
- **Remediation in v1.7.0**:
  - `SupabaseConnector` performs live REST endpoint ping measurement; on error, returns clean failure (`isSuccess = false`) with `null` metric fields.
  - `VercelConnector` parses live Vercel deployments API; on error, returns clean failure without fallback data.
- **Verification**: `StackConnectorsTest.kt` verifies error scenarios return zero fake numbers.

## 4. Connect Auth Architecture & Provider Matrix

- **ProviderRegistry**: Dynamic catalog for GitHub, Cloudflare, Supabase, Vercel, Firebase/GCP, OpenAI API, Anthropic API, Custom Service, Codex, Claude Code, and Antigravity.
- **OAuthPkceManager**:
  - 48-byte cryptographically secure code verifier generation (Base64URL encoded).
  - SHA-256 code challenge generation.
  - Constant-time state validation.
  - Redirect callback parsing.
  - Token storage in Android Keystore and connection record in Room `ProviderConnectionEntity`.
- **Verification**: `ProviderRegistryTest.kt` (4 tests) and `OAuthPkceTest.kt` (5 tests) all pass.
