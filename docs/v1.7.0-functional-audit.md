## 2. Integration Data Integrity & Cascade Elimination

- **Problem**: In previous versions, `IntegrationEntity` used `@Insert(onConflict = REPLACE)`. Because child entities have `onDelete = CASCADE`, updates deleted all metrics and incidents. Furthermore, direct `insertIntegration` calls in `CloudflareSyncer` and `GitHubSyncer` caused `OnConflictStrategy.ABORT` crashes.
- **Remediation**:
  - Added `@Transaction suspend fun upsertIntegrationNonDestructively(integration)` on `IntegrationDao`.
  - Migrated all syncers (`GitHubSyncer`, `CloudflareSyncer`, `SupabaseSyncer`, `VercelSyncer`, `AppDataInitializer`) to non-destructive upserts.
- **Verification**: `IntegrationCascadePreservationTest.kt` and `GitHub304Test.kt` assert that child metrics and incidents survive repeated syncs across all integrations.
